# Revisi Responsif Formulir — Versi 19

Perubahan pada `order-sekarang.html`:
- Lebar kartu formulir dibatasi hingga 440px pada layar berukuran 520px atau lebih kecil, dengan lebar tetap mengikuti layar jika ruang tersedia.
- Padding kartu, jarak antarkolom, ringkasan pembayaran, dan elemen status alamat diperkecil agar tampilan HP lebih ringkas.
- Kolom input dibatasi agar tidak melebar keluar dari kartu; ukuran teks input 16px untuk mengurangi zoom otomatis pada Safari iPhone.
- Pada layar tablet, lebar kartu dibatasi hingga 560px agar tidak terlalu melebar.

Catatan: perubahan ini menyesuaikan tampilan formulir pemesanan di `order-sekarang.html`. Pengujian dilakukan dengan memeriksa perubahan CSS dan struktur arsip, bukan pengujian visual langsung di seluruh perangkat.
